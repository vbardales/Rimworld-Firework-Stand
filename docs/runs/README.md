# Pickle runs: history

`history.md` holds one text line per Pickle run (what ran, the result, what it taught, whether its evidence still exists). Evidence itself (reports, captures, films) is on disk and out of git, under `Tests/Pickle/Inbox/`, `Parked/` and `Evidence/` (see `Tests/Pickle/README.md`, "Evidence"). Read `exitReason` before the counts.

`STATUS-journal-to-2026-10-11.md` is the status journal up to the audit of 2026-10-11. The per-run summaries written before 2026-10-20 were folded into `history.md`; the files are in git history.
